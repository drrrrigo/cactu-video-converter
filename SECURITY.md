# Security policy

The first public beta is supported on a best-effort basis. No stable-production
security maintenance promise is made for beta candidates.

Please report suspected vulnerabilities using
[GitHub private vulnerability reporting](https://github.com/drrrrigo/cactu-video-converter/security/advisories/new).
Do not post exploit details, secrets, private media or unreviewed logs as an ordinary
public issue. If private reporting is temporarily unavailable, do not open a public
exploit report; use a non-sensitive issue asking the maintainer to restore the
private reporting channel, without describing the vulnerability publicly.

Include the version, OS/package type, impact and a minimal synthetic reproduction
where practical. Review diagnostics/logs for private paths before attaching them.
Cactu has no automatic telemetry, crash upload or remote media processing. Only
explicit user actions open the repository, issue page or registered official driver
support pages. Build-time dependency downloads are documented separately.
