# Presets

`Web Compatibility / Kosmi` creates MP4 output named
`OriginalName-Kosmi.mp4`, H.264 CRF 18/medium/yuv420p, AAC 256 kbps,
source channels, and Faststart. Codec choices default to **Auto**, allowing
the planner to copy existing compatible H.264 and AAC instead of encoding them.

Editing a setting marks the selection “Custom — based on Web Compatibility /
Kosmi”. Restore Preset Defaults resets all controls. This preset only prepares
local media for broad browser playback and has no Kosmi integration.
