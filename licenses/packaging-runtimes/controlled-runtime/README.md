# Controlled AppImage runtime notices

These notices accompany the Cactu-controlled fedfad51-cactu1 static runtime.
libfuse and squashfuse texts are retained in the parent packaging-runtimes tree.
The zstd library uses its BSD-3-Clause alternative; musl/mimalloc use their
individual MIT/BSD notices, zlib its own terms, and GCC target runtime code its
applicable runtime exception. Linux UAPI headers retain their syscall exception.
Exact sources, Alpine recipe/patch commits, APK hashes and relink input hashes
are recorded in release/appimage-controlled-lock.json. Complete source/relinking
material is retained locally pending maintained recipient delivery and human
review. No blanket redistribution approval follows from these texts.
